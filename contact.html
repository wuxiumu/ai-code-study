邮件联系

最稳妥的方式是直接发邮件。我们会在 1–3 个工作日内回复。

hi@ai-code-study.chiguashentan.com

请在邮件标题里写明来意，例如：

  • 【内容纠错】PyTorch 安装命令在 macOS 下失效

  • 【友情链接】申请交换链接
  • 【教程建议】希望增加 JAX / MLX 教程

开源贡献

本站内容托管在 GitHub，欢迎你通过 Issue 或 Pull Request 参与：

  • 发现错字/代码错误 → 直接提 PR 修改 HTML
  • 想新增教程 → 先开 Issue 讨论大纲
  • 发现页面样式问题 → 附带浏览器版本和截图
GitHub 仓库地址请在 assets/config.js 中替换为真实地址。
